# SkillWave Website

> **Your complete learning workspace for tech careers.**

SkillWave Website is the modern marketing and product-introduction website for the SkillWave learning platform.

The website introduces SkillWave, explains its learning experience, presents its learning formats, helps users understand how the platform works, and provides entry points for getting started and logging in.

SkillWave is designed for students and technology professionals who want to learn technology subjects, strengthen their technical knowledge, and prepare for technical interviews through multiple learning formats.

---

## 📌 Project Overview

SkillWave brings different technology-learning resources together into one focused learning experience.

The platform is designed around five primary learning formats:

- **Courses**
- **Interview Q&A**
- **Videos**
- **Slideshows**
- **Audio**

The website acts as the visual and informational entry point to the SkillWave ecosystem.

It focuses on:

- Introducing the SkillWave platform
- Explaining the available learning formats
- Showing how SkillWave can be used
- Identifying the different types of learners SkillWave supports
- Helping users discover learning directions
- Providing a clear path toward getting started
- Providing a login entry point for existing users
